## 1. 一页需求说明

### 1.1 一句话

把校园里正在消失的声音钉在地图上，点开就能听、能看、能读它背后的故事。

### 1.2 背景与问题

校园声音是集体记忆的一部分：闭馆铃、打菜窗口的嘈杂、操场的哨声、宿舍楼下的猫叫。但现有的校园地图只有文字和照片，缺少「听觉」这一维；老食堂改造、旧教学楼翻新之后，这些声音就彻底消失了。本项目用一张可听的地图，为校园留下一份声音档案。

### 1.3 目标用户与典型场景

| 用户 | 场景 |
|---|---|
| 新生 | 还没走遍校园，先用声音认识每个角落 |
| 在校生 | 按图索骥去「打卡」某个声音，或纯好奇探索 |
| 校友 | 离开学校后，远程听一听熟悉的声音 |
| 评委/观众 | 答辩现场被一段声音勾起共鸣，愿意继续点下去 |

### 1.4 范围

| 做 | 不做 |
|---|---|
| 1 张校园地图，8–12 个声音点 | 用户注册、上传、评论 |
| 详情页：播放、波形、故事、照片 | 后台管理系统 |
| 分类筛选：学习 / 生活 / 运动 / 自然 | 多校区、跨城市 |
| 「盲听猜地点」小互动 | 实时录音、AI 声音识别 |
| 一张可保存的分享卡 | 社交关系链、排行榜 |

### 1.5 功能优先级

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 地图打点 + 点击播放 | 每个点对应一条声音，弹层显示标题与播放键 |
| P0 | 详情页 | 音频、波形、地点、时长、故事、署名 |
| P0 | 列表与分类筛选 | 四个类别 + 「全部」，可与地图联动 |
| P1 | 波形可视化 | Wavesurfer.js，播放时高亮进度 |
| P1 | 盲听猜地点 | 先听声音，再从 3 个地点里选，答对给反馈 |
| P2 | 分享卡 | 生成「声音档案卡」图片，可保存 |
| P2 | 声音时间轴 / 热力图 | 时间富余再做，默认砍掉 |

### 1.6 非功能需求

- 首屏加载 ≤ 2 秒（校园网环境）。
- 移动端 375px 宽度起可完整使用。
- 单条音频 ≤ 1 MB，全部音频总量 ≤ 12 MB。
- 断网时地图瓦片允许缺失，但音频与详情页必须可用（资源本地化）。
- 兼容 Chrome / Edge / Safari 最近两个大版本。

### 1.7 验收标准

1. ≥ 8 条声音可正常播放，无 404、无静音文件。
2. 地图点与 `sounds.json` 一一对应，点击弹层内容正确。
3. 详情页信息完整：标题、地点、类别、时长、故事、录制者署名。
4. 手机端可完整走通「打开地图 → 点声音 → 播放 → 看故事」。
5. 3 分钟演示脚本可一次跑通，不依赖现场网络。
6. 浏览器控制台无报错。

### 1.10 风险与对策

| 风险 | 对策 |
|---|---|
| 录音质量差 | 每条录 3 遍，现场戴耳机试听，不合格立即重录 |
| 隐私与版权 | 只录公共环境声，避开可识别对话，全部自制并署名 |
| 地图瓦片加载慢 | 提前缓存底图，或改用静态校园底图 + 坐标换算 |
| 音频格式不兼容 | 统一导出 MP3 128kbps，保留 M4A 原始文件 |
| 进度拖延 | D3 冻结声音清单，之后只做减法，不再加功能 |

## 2. 内容 Schema

`src/data/sounds.json` 是唯一数据源。地图、列表、详情页、盲听互动全部从它读取，不允许在组件里硬编码声音内容。

### 2.1 文件结构

```text
project/
├─ public/
│  ├─ audio/
│  │  ├─ raw/          # 原始录音，不部署
│  │  └─ final/        # snd-001.mp3 ...
│  └─ images/          # snd-001.jpg ...
├─ src/
│  ├─ data/
│  │  └─ sounds.json   # 唯一内容源
│  ├─ components/
│  └─ pages/
```

### 2.2 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `version` | string | 是 | Schema 版本，固定 `"1.0"` |
| `campus.name` | string | 是 | 校区名称 |
| `campus.center` | `[number, number]` | 是 | 地图初始中心 `[lng, lat]` |
| `campus.zoom` | number | 是 | 初始缩放级别，建议 16–17 |
| `campus.bounds` | `[[number, number], [number, number]]` | 是 | 校区经纬度范围，用于校验打点 |
| `categories` | `Category[]` | 是 | 四个固定分类 |
| `sounds` | `Sound[]` | 是 | 声音条目，8–12 条 |

### 2.3 声音字段

| 字段 | 类型 | 必填 | 说明 / 约束 |
|---|---|---|---|
| `id` | string | 是 | `snd-001` 格式，全局唯一，与文件名一致 |
| `title` | string | 是 | ≤ 12 字，如「图书馆闭馆铃」 |
| `category` | enum | 是 | `study` / `life` / `sport` / `nature` |
| `zone` | enum | 是 | 教学区 / 生活区 / 运动区 / 自然区 / 校门口 |
| `location.name` | string | 是 | 具体到楼或点位 |
| `location.lng` | number | 是 | 经度，落在 `campus.bounds` 内 |
| `location.lat` | number | 是 | 纬度，落在 `campus.bounds` 内 |
| `location.precision` | enum | 是 | `building` / `spot` / `area` |
| `audio.src` | string | 是 | 如 `/audio/final/snd-001.mp3` |
| `audio.duration` | number | 是 | 秒，与实际时长误差 ≤ 1 秒 |
| `audio.format` | string | 是 | 固定 `mp3` |
| `audio.recorded_at` | string | 是 | ISO 8601，带时区 |
| `audio.device` | string | 否 | 如 `iPhone 13` |
| `cover` | string | 否 | 封面图路径，建议 4:3 |
| `story` | string | 是 | 50–150 字，讲声音背后的场景或记忆 |
| `transcript` | string | 否 | 有人声时的文字转写 |
| `tags` | string[] | 是 | ≤ 5 个，用于检索 |
| `credit.recorded_by` | string | 是 | 录制者姓名 |
| `credit.edited_by` | string | 否 | 后期处理者 |
| `credit.license` | enum | 是 | `CC BY-NC 4.0` / `CC BY 4.0` / `内部教学使用` |
| `status` | enum | 是 | `draft` / `review` / `published` |
| `order` | number | 是 | 详情页与列表排序，从 1 开始 |

### 2.5 TypeScript 类型

```ts
export type CategoryId = "study" | "life" | "sport" | "nature";
export type Zone = "教学区" | "生活区" | "运动区" | "自然区" | "校门口";
export type Status = "draft" | "review" | "published";
export type License = "CC BY-NC 4.0" | "CC BY 4.0" | "内部教学使用";

export interface Category {
  id: CategoryId;
  name: string;
  color: string;
}

export interface Sound {
  id: string;
  title: string;
  category: CategoryId;
  zone: Zone;
  location: {
    name: string;
    lng: number;
    lat: number;
    precision: "building" | "spot" | "area";
  };
  audio: {
    src: string;
    duration: number;
    format: "mp3";
    recorded_at: string;
    device?: string;
  };
  cover?: string;
  story: string;
  transcript?: string;
  tags: string[];
  credit: {
    recorded_by: string;
    edited_by?: string;
    license: License;
  };
  status: Status;
  order: number;
}

export interface SoundData {
  version: string;
  campus: {
    name: string;
    center: [number, number];
    zoom: number;
    bounds: [[number, number], [number, number]];
  };
  categories: Category[];
  sounds: Sound[];
}
```

### 2.6 校验规则

| 规则 | 说明 |
|---|---|
| `id` 唯一且匹配 `^snd-\d{3}$` | 与音频文件名一致 |
| `audio.src` 必须存在 | 构建前跑一次文件存在性检查 |
| `duration` 误差 ≤ 1 秒 | 用 `ffprobe` 或播放器读取真实时长 |
| `lng/lat` 在 `bounds` 内 | 防止打点到校外 |
| `story` 50–150 字 | 太短没内容，太长没人读 |
| `tags` ≤ 5 个 | 超出则丢弃低价值标签 |
| `status=published` 才上线 | `draft` / `review` 不渲染 |
| 音频总大小 ≤ 12 MB | 超过则降码率或减条目 |

### 3.3 录制 SOP

1. **提前踩点**：确认声音出现的时间、位置、持续多久，避免白跑。
2. **设备**：手机即可；有耳机麦更好。关闭「降噪 / 风噪抑制 / 自动增益」。
3. **距离**：声源 0.5–2 m；录环境声退到 3–5 m。
4. **每条录 3 遍**：近景、中景、环境各一遍，回宿舍挑最好的一条。
5. **时长**：单条 15–40 秒；纯环境声可到 60 秒。
6. **留白**：开头留 0.5 秒环境音，结尾自然淡出，不要戛然而止。
7. **现场试听**：戴耳机确认无爆音、无电流声、无他人清晰对话。
8. **当场登记**：编号、时间、地点、设备、是否重录，填进 3.2 的表。

### 3.4 命名与目录

```text
原始：snd-001_library-bell_20261123.m4a
成品：snd-001.mp3
```

- 全小写、连字符分隔、不加中文，避免部署后路径编码问题。
- 日期用 `YYYYMMDD`。
- 原始文件留在 `public/audio/raw/`，不部署；成品放 `public/audio/final/`。
- 封面图同名：`snd-001.jpg`。

### 3.5 质检清单

- [ ] 无爆音、无削波
- [ ] 无风噪、无电流声
- [ ] 无清晰可辨的他人隐私对话
- [ ] 声源可辨识，3 秒内能听出是什么
- [ ] 时长 8–60 秒
- [ ] 开头不空白，结尾自然
- [ ] 响度统一（约 -16 LUFS）
- [ ] 已登记录制者与授权方式
- [ ] 文件命名符合规范

### 3.6 伦理与版权

- 只录公共空间的环境声，不进入私人场所。
- 避开可识别的私人对话；无法避开时后期剪掉或重录。
- 不录商业音乐、影视片段、他人作品的外放。
- 涉及具体个人（如接受采访）需口头同意，并记录。
- 统一授权：`CC BY-NC 4.0` 或「内部教学使用」，详情页署名录制者。
- 上线前由 R1 统一审核一遍素材来源。
