## 1. 一页需求说明

### 1.1 一句话

把校园里正在消失的声音钉在地图上，点开就能听、能看、能读它背后的故事；拖动时间轴，还能听见同一座校园从清晨到深夜的变化。

### 1.2 背景与问题

校园声音是集体记忆的一部分：闭馆铃、打菜窗口的嘈杂、操场的哨声、宿舍楼下的猫叫。但现有的校园地图只有文字和照片，缺少「听觉」这一维；而且声音是随时间变化的——清晨的鸟鸣、正午的食堂、黄昏的广播、深夜的闭馆铃，静态地图把这条时间线压平了。老食堂改造、旧教学楼翻新之后，这些声音还会彻底消失。

本项目用一张可听的地图 + 一条 24 小时时间轴，为校园留下一份有声档案。

### 1.3 目标用户与典型场景

| 用户 | 场景 |
|---|---|
| 新生 | 还没走遍校园，先用声音认识每个角落 |
| 在校生 | 按图索骥去「打卡」某个声音，或拖动时间轴看校园的一天 |
| 校友 | 离开学校后，远程听一听熟悉的声音 |
| 评委/观众 | 答辩现场被「播放一天」打动，愿意继续点下去 |

### 1.4 范围

| 做 | 不做 |
|---|---|
| 1 张校园地图，8–12 个声音点 | 四季时间轴（列为扩展点，见第 5 节） |
| 详情页：播放、波形、故事、照片 | 用户注册、上传、评论 |
| 分类筛选：学习 / 生活 / 运动 / 自然 | 后台管理系统 |
| 一日时间轴：0–24h 滑块 + 6 个时段主题 | 多校区、跨城市 |
| 「播放一天」自动演示 | 实时录音、AI 声音识别 |
| 盲听猜地点、分享卡（P2） | 社交关系链、排行榜 |

### 1.5 功能优先级

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 地图打点 + 点击播放 | 每个点对应一条声音，弹层显示标题与播放键 |
| P0 | 详情页 | 音频、波形、地点、时长、故事、署名 |
| P0 | 列表与分类筛选 | 四个类别 + 「全部」，可与地图联动 |
| P0 | 一日时间轴 | 0–24h 滑块，6 个时段切换主题与声音 |
| P1 | 波形可视化 | Wavesurfer.js，播放时高亮进度 |
| P1 | 盲听猜地点 | 先听声音，再从 3 个地点里选，答对给反馈 |
| P1 | 「播放一天」 | 90 秒自动走完 6 个时段，按时间触发声音 |
| P1 | 详情页时间条 | 该地点的时段序列，空缺显示「待补录」 |
| P2 | 分享卡 | 生成「声音档案卡」图片，可保存 |

> 四季时间轴不在本期范围，仅作为扩展点保留，见第 5 节。

### 1.6 非功能需求

- 首屏加载 ≤ 2 秒（校园网环境）。
- 移动端 375px 宽度起可完整使用。
- 单条音频 ≤ 1 MB，全部音频总量 ≤ 12 MB。
- 断网时地图瓦片允许缺失，但音频与详情页必须可用（资源本地化）。
- 拖动时间轴时 ≥ 50fps（中端手机）。
- 时段主题切换 600–800ms，不闪白、不跳变。
- 首屏预加载音频 ≤ 6 条，其余点击后再加载。
- 开启 `prefers-reduced-motion` 时关闭粒子与自动播放。
- 兼容 Chrome / Edge / Safari 最近两个大版本。

### 1.7 验收标准

1. ≥ 8 条声音可正常播放，无 404、无静音文件。
2. 地图点与 `sounds.json` 一一对应，点击弹层内容正确。
3. 详情页信息完整：标题、地点、类别、时长、故事、录制者署名。
4. 拖动时间轴到 6 个时段，主题、地图色调、粒子正确切换。
5. 当前时段的声音点在图上高亮，其余点降低透明度。
6. 点「播放一天」后 90 秒内自动走完 6 个时段，声音按序触发，无卡死。
7. 详情页时间条：已录时段可点击播放，空缺时段显示「待补录」且不报错。
8. 手机端可完整走通「打开地图 → 拖时间轴 → 点声音 → 播放 → 看故事」。
9. 3 分钟演示脚本可一次跑通，不依赖现场网络。

### 1.10 风险与对策

| 风险 | 对策 |
|---|---|
| 录音质量差 | 每条录 3 遍，现场戴耳机试听，不合格立即重录 |
| 隐私与版权 | 只录公共环境声，避开可识别对话，全部自制并署名 |
| 地图瓦片加载慢 | 提前缓存底图，或改用静态校园底图 + 坐标换算 |
| 音频格式不兼容 | 统一导出 MP3 128kbps，保留 M4A 原始文件 |
| 进度拖延 | D3 冻结声音清单，之后只做减法，不再加功能 |
| 时间轴切换卡顿 | 主题只改 CSS 变量，滤镜只作用于瓦片层 |
| 自动播放被拦截 | 必须由「播放一天」按钮点击触发 |
| 时段数据不全 | 空缺显示「待补录」，不阻塞主流程 |
| 同机位照片光线不一致 | 固定机位、同一焦段、手动曝光，后期只统一色调 |

## 2. 内容 Schema

`src/data/sounds.json` 是唯一数据源。地图、列表、详情页、时间轴、盲听互动全部从它读取，不允许在组件里硬编码声音内容。

### 2.1 文件结构

```text
project/
├─ public/
│  ├─ audio/
│  │  ├─ raw/          # 原始录音，不部署
│  │  └─ final/        # snd-001.mp3 ...
│  └─ images/          # snd-001.jpg / timeline-dawn.jpg ...
├─ src/
│  ├─ data/
│  │  └─ sounds.json   # 唯一内容源
│  ├─ components/
│  └─ pages/
```

### 2.2 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `version` | string | 是 | Schema 版本，固定 `"1.1"` |
| `campus.name` | string | 是 | 校区名称 |
| `campus.center` | `[number, number]` | 是 | 地图初始中心 `[lng, lat]` |
| `campus.zoom` | number | 是 | 初始缩放级别，建议 16–17 |
| `campus.bounds` | `[[number, number], [number, number]]` | 是 | 校区经纬度范围，用于校验打点 |
| `categories` | `Category[]` | 是 | 四个固定分类 |
| `series` | `Series[]` | 否 | 时间轴分组，本期至少一条「校园的一天」 |
| `sounds` | `Sound[]` | 是 | 声音条目，8–12 条 |

### 2.3 声音字段

| 字段 | 类型 | 必填 | 说明 / 约束 |
|---|---|---|---|
| `id` | string | 是 | `snd-001` 格式，全局唯一，与文件名一致 |
| `title` | string | 是 | ≤ 12 字，如「图书馆闭馆铃」 |
| `category` | enum | 是 | `study` / `life` / `sport` / `nature` |
| `zone` | enum | 是 | 教学区 / 生活区 / 运动区 / 自然区 / 校门口 |
| `location.name` | string | 是 | 具体到楼或点位 |
| `location.lng` | number | 是 | 经度，落在 `campus.bounds` 内 |
| `location.lat` | number | 是 | 纬度，落在 `campus.bounds` 内 |
| `location.precision` | enum | 是 | `building` / `spot` / `area` |
| `audio.src` | string | 是 | 如 `/audio/final/snd-001.mp3` |
| `audio.duration` | number | 是 | 秒，与实际时长误差 ≤ 1 秒 |
| `audio.format` | string | 是 | 固定 `mp3` |
| `audio.recorded_at` | string | 是 | ISO 8601，带时区 |
| `audio.device` | string | 否 | 如 `iPhone 13` |
| `cover` | string | 否 | 封面图路径，建议 4:3 |
| `story` | string | 是 | 50–150 字，讲声音背后的场景或记忆 |
| `transcript` | string | 否 | 有人声时的文字转写 |
| `tags` | string[] | 是 | ≤ 5 个，用于检索 |
| `time.axis` | enum | 是 | `day`（本期）/ `year`（扩展预留） |
| `time.slot` | enum | 是 | day：`dawn` / `morning` / `noon` / `afternoon` / `dusk` / `night`；year：`spring` / `summer` / `autumn` / `winter` |
| `time.label` | string | 是 | 展示用，如 `21:55`、`7 月` |
| `time.series_id` | string | 否 | 关联 `series[].id`，用于详情页时间条 |
| `credit.type` | enum | 是 | `field` 现场采集 / `archive` 档案素材 |
| `credit.recorded_by` | string | 是 | 录制者或素材作者 |
| `credit.edited_by` | string | 否 | 后期处理者 |
| `credit.library` | string | 条件 | `type=archive` 时必填，如 `Freesound` |
| `credit.url` | string | 条件 | `type=archive` 时必填，素材原始链接 |
| `credit.license` | enum | 是 | `CC0` / `CC BY 4.0` / `CC BY-NC 4.0` / `内部教学使用` |
| `status` | enum | 是 | `draft` / `review` / `published` |
| `order` | number | 是 | 详情页与列表排序，从 1 开始 |

### 2.5 TypeScript 类型

```ts
export type CategoryId = "study" | "life" | "sport" | "nature";
export type Zone = "教学区" | "生活区" | "运动区" | "自然区" | "校门口";
export type Status = "draft" | "review" | "published";
export type License = "CC0" | "CC BY 4.0" | "CC BY-NC 4.0" | "内部教学使用";

export type TimeAxis = "day" | "year";
export type DaySlot = "dawn" | "morning" | "noon" | "afternoon" | "dusk" | "night";
export type YearSlot = "spring" | "summer" | "autumn" | "winter";
export type TimeSlot = DaySlot | YearSlot;

export interface Category {
  id: CategoryId;
  name: string;
  color: string;
}

export interface TimeInfo {
  axis: TimeAxis;
  slot: TimeSlot;
  label: string;
  series_id?: string;
}

export interface Series {
  id: string;
  title: string;
  axis: TimeAxis;
  slots: TimeSlot[];
}

export interface Credit {
  type: "field" | "archive";
  recorded_by: string;
  edited_by?: string;
  library?: string;
  url?: string;
  license: License;
}

export interface Sound {
  id: string;
  title: string;
  category: CategoryId;
  zone: Zone;
  location: {
    name: string;
    lng: number;
    lat: number;
    precision: "building" | "spot" | "area";
  };
  audio: {
    src: string;
    duration: number;
    format: "mp3";
    recorded_at: string;
    device?: string;
  };
  cover?: string;
  story: string;
  transcript?: string;
  tags: string[];
  time: TimeInfo;
  credit: Credit;
  status: Status;
  order: number;
}

export interface SoundData {
  version: string;
  campus: {
    name: string;
    center: [number, number];
    zoom: number;
    bounds: [[number, number], [number, number]];
  };
  categories: Category[];
  series?: Series[];
  sounds: Sound[];
}
```

### 2.6 校验规则

| 规则 | 说明 |
|---|---|
| `id` 唯一且匹配 `^snd-\d{3}$` | 与音频文件名一致 |
| `audio.src` 必须存在 | 构建前跑一次文件存在性检查 |
| `duration` 误差 ≤ 1 秒 | 用 `ffprobe` 或播放器读取真实时长 |
| `lng/lat` 在 `bounds` 内 | 防止打点到校外 |
| `story` 50–150 字 | 太短没内容，太长没人读 |
| `tags` ≤ 5 个 | 超出则丢弃低价值标签 |
| `status=published` 才上线 | `draft` / `review` 不渲染 |
| 音频总大小 ≤ 12 MB | 超过则降码率或减条目 |
| `axis=day` 时 `slot` 必须是 6 个时段之一 | 反之 `axis=year` 时必须是四季之一 |
| `series_id` 若存在，必须能在 `series[]` 中找到 | 否则时间条渲染失败 |
| 同一 `series_id + slot` 只允许一条 `published` | 防止时间条出现重复 |
| `credit.type=archive` 时 `library`、`url` 必填 | 保证来源可追溯 |

### 3.3 录制 SOP

1. **提前踩点**：确认声音出现的时间、位置、持续多久，避免白跑。
2. **设备**：手机即可；有耳机麦更好。关闭「降噪 / 风噪抑制 / 自动增益」。
3. **距离**：声源 0.5–2 m；录环境声退到 3–5 m。
4. **每条录 3 遍**：近景、中景、环境各一遍，回宿舍挑最好的一条。
5. **时长**：单条 15–40 秒；纯环境声可到 60 秒。
6. **留白**：开头留 0.5 秒环境音，结尾自然淡出，不要戛然而止。
7. **现场试听**：戴耳机确认无爆音、无电流声、无他人清晰对话。
8. **当场登记**：编号、时间、地点、设备、是否重录，填进 3.2 的表。

### 3.4 命名与目录

```text
原始：snd-001_library-bell_20261123.m4a
成品：snd-001.mp3
```

- 全小写、连字符分隔、不加中文，避免部署后路径编码问题。
- 日期用 `YYYYMMDD`。
- 原始文件留在 `public/audio/raw/`，不部署；成品放 `public/audio/final/`。
- 封面图同名：`snd-001.jpg`。

### 3.5 质检清单

- [ ] 无爆音、无削波
- [ ] 无风噪、无电流声
- [ ] 无清晰可辨的他人隐私对话
- [ ] 声源可辨识，3 秒内能听出是什么
- [ ] 时长 8–60 秒
- [ ] 开头不空白，结尾自然
- [ ] 响度统一（约 -16 LUFS）
- [ ] 已登记录制者与授权方式
- [ ] 文件命名符合规范

### 3.6 伦理与版权

- 只录公共空间的环境声，不进入私人场所。

- 不录商业音乐、影视片段、他人作品的外放。

## 4. 一日时间轴设计（本期实现）

### 4.1 概念

一天切成 6 段，时间轴既是导航也是内容：拖动时间，地图色调、粒子、当前时段的声音一起变化。项目从「一张能听的地图」升级为「一件关于一天的作品」。

### 4.2 时段定义

| slot | 时间范围 | 名称 | 主题色 | 粒子 | 代表声音 |
|---|---|---|---|---|---|
| `dawn` | 05:30–07:00 | 黎明 | `#2E3A59 → #E8A87C` | 薄雾 | 清晨鸟鸣 |
| `morning` | 07:00–11:00 | 上午 | `#F5F1E8 / #7FA6C9` | 无 | 上课预备铃 |
| `noon` | 11:00–14:00 | 正午 | `#FFF8E7 / #E0B15C` | 热浪 | 食堂刷卡 |
| `afternoon` | 14:00–17:00 | 下午 | `#F3E2C7 / #C98B5E` | 无 | 图书馆翻书 / 操场 |
| `dusk` | 17:00–19:00 | 黄昏 | `#6B4C7A → #F08A5D` | 飞鸟 | 黄昏广播 |
| `night` | 19:00–05:30 | 夜晚 | `#0F1B2D / #3E6B8F` | 萤火 | 闭馆铃 / 猫叫 |

### 4.3 现有素材归位

| 时段 | 声音 | ID | 采集状态 |
|---|---|---|---|
| 黎明 | 清晨鸟鸣 | S08 | 现场 |
| 上午 | 上课预备铃 | S02 | 现场 |
| 正午 | 食堂刷卡 / 窗口嘈杂 | S03 / S04 | 现场 |
| 下午 | 图书馆翻书 / 操场哨声 | S13 / S05 | 现场 |
| 黄昏 | 黄昏校园广播 | T01 | **需补录 1 条** |
| 夜晚 | 闭馆铃 / 猫叫 | S01 / S07 | 现场 |

结论：8 条 P0 全部能用，日轴只增加 1 条录音的工作量。

### 4.4 交互

1. **底部时间滑块**：0–24h，设 6 个停靠点；不做连续插值，降低实现难度。
2. **切换主题**：拖动或点击停靠点，根节点切 `data-slot`，600ms 过渡；当前时段的声音点高亮，其余点降低透明度。
3. **详情页时间条**：显示该地点 `series` 的所有时段；已录可点击播放，空缺显示「待补录」。
4. **「播放一天」**：90 秒，6 段 × 15 秒；每段开始切换主题并播放该时段代表声音，环境底噪循环；可暂停、可拖动进度。
5. **键盘可用**：滑块支持 ← / →；移动端加大触控热区。
6. **自动播放限制**：必须由按钮点击触发，避免被浏览器策略拦截。

### 4.5 视觉差分

主题统一用 CSS 变量，组件里不写死颜色：

```css
:root[data-slot="dawn"] {
  --sky-top: #2E3A59;
  --sky-bottom: #E8A87C;
  --accent: #E8A87C;
  --tile-filter: sepia(.15) hue-rotate(-15deg) brightness(.95) saturate(.9);
}
```

地图滤镜只作用于 `.leaflet-tile-pane`，不要给整个页面加 `filter`：

| 时段 | 瓦片滤镜 |
|---|---|
| 黎明 | `sepia(.15) hue-rotate(-15deg) brightness(.95) saturate(.9)` |
| 上午 | `brightness(1.05) saturate(1.05)` |
| 正午 | `contrast(1.05) brightness(1.02)` |
| 下午 | `sepia(.1) saturate(1.05)` |
| 黄昏 | `sepia(.2) hue-rotate(-10deg) brightness(.92)` |
| 夜晚 | `brightness(.55) saturate(.7) hue-rotate(190deg)` |

其他差分手段：

- **同机位照片**：P01–P04 按当前时段切换，放在详情页或时间轴背景。
- **粒子**：一个 Canvas 组件，`mode` 传 `mist / heat / bird / firefly`，页面隐藏时暂停。
- **波形**：进度色用 `--accent`，与主题统一。
- **夜景对比度**：夜晚主题下正文不要用纯白，用 `#E6EDF5`，避免刺眼。

### 4.6 实现要点

- 主题配置放 `src/themes.ts`，按 slot 导出 `{ sky, accent, tileFilter, particle }`。
- `minute → slot` 用一个纯函数映射，边界值写进配置，测试时好改。
- 首屏只预加载 6 条代表声音；其余点击详情后再加载。
- 播放用 WebAudio `GainNode` 做 300ms 交叉淡入淡出，避免切歌爆音。
- 「播放一天」用 `requestAnimationFrame` 驱动 90 秒时间轴，`visibilitychange` 时暂停。
- 粒子在低端机降级为静态渐变；尊重 `prefers-reduced-motion`。
- 地图滤镜是性能热点，只在瓦片层加，并避免同时叠加 `box-shadow`、`backdrop-filter`。

### 4.7 本期范围与取舍

- **做**：6 个时段、一条「校园的一天」、8–10 条声音、时间滑块、「播放一天」、详情页时间条。
- **不做**：24h 连续插值、多地点 series、四季模式、分享卡（P2 最后做）。
- **加码项**：D7 之后若有余力，再加第二条 series（如「食堂的一天」）。

## 5. 四季时间轴（扩展点，本期不做）

### 5.1 定位

年轴，主题式，不要求同一地点。与日轴的区别：日轴比「同一地点的不同时刻」，年轴比「同一座校园的不同季节」。

### 5.2 数据策略

两周期内不可能现场采集四季，可行的组合是：

- **当季现场录 1 条**（11 月是深秋，录落叶、风声、运动会）；
- **其余 3 季从 CC0 素材库补**；
- 只选**天气、自然、动物**类声音（雨、蝉、雪、风、鸟），这类声音没有地域口音，不容易穿帮；
- **避开人声广播、方言、校园通知**，一听就知道不是本校。

### 5.3 素材来源与授权

| 来源 | 授权 | 备注 |
|---|---|---|
| Freesound | CC0 / CC BY | 优先筛 CC0，必须登记作者与链接 |
| Pixabay Audio | 免费商用 | 仍需记录来源 |
| Internet Archive | Public Domain | 老录音多，质量参差 |
| 耳聆网 / 淘声网 | 多为 CC | 中文声音多，逐个确认原始授权 |
| BBC Sound Effects | RemArc | 仅个人/教育用途，商用不可 |

**不可使用**：YouTube、B 站、抖音直接扒音轨；商业音乐；影视片段。

### 5.4 届时需要的改动

Schema 已经预留 `axis: "year"` 与四季 slot，数据结构不用动，只需：

- 顶部加「一天 / 一年」模式切换；
- 增加 4 套季节主题与粒子；
- 年轴 4 段，「播放一年」60 秒；
- 预计 2–3 人天。

### 5.5 为什么本期不做

- 两周内无法现场采集四季，硬凑会失真；
- 素材库声音与校园声景存在风格差；
- 会稀释日轴的核心完成度；
- 先把「一天」做扎实，四季作为答辩时的 roadmap 讲，反而显得边界清楚。

### 5.6 如果启用，必须做的来源标注

- `credit.type = archive`，`library`、`url` 必填；
- UI 给每条声音打徽章：「现场采集」/「档案素材」；
- 答辩时主动说明补了哪几季、为什么补，比假装全部现场录制的更加分。
