# 个人文件库（people/）

一人一个目录，目录名用 GitHub 名。这里是**个人**的东西，不是项目代码。

## 放什么
- 自己的提案素材：参考名单、案例链接、截图、笔记、草稿
- 自己的 AI 对话要点、失败尝试、半成品
- 自己的素材来源记录（正式引用仍写进 `docs/design/素材来源.md`）

## 不放什么
- 密钥、真实个人信息——仓库是公开的
- 对同学作品的评价——要写就写在自己电脑上
- 大文件（视频 / 原图 > 10 MB）：放群网盘，这里只写链接

## 和项目线的区别
| | 这里 `people/<名>/` | 项目 `src/features/<切片>/` |
|---|---|---|
| 归谁 | 个人 | 团队 |
| 要评审吗 | 不要 | 要（组长审计） |
| 进构建吗 | 不进 | 进 |
| 能删吗 | 随便删 | 要走 PR |

## 怎么上传（免审计，自己合）
1. 在 `people/<你的 GitHub 名>/` 下加文件，按平时流程 commit、push、开 PR；
2. `audit-gate` 检查会自动变绿（只改 people/ 就是免审计）；
3. 自己点 **Merge pull request** 就行，不用等谁 approve。

> 一个 PR 里只要混进 `people/` 以外的任何文件，就会变成"要组长审计"，检查变红、合不进去——所以素材别放错位置。

## 命名
- 目录名 = GitHub 名（**这是全仓唯一允许出现人名的位置**）。
- 不建 `people/前端组/`、`people/杂项/` 这种——按人就是按人。
