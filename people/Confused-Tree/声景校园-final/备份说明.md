# 备份 0 · 声景校园（粒子波纹基线）

这是本项目的**第一版**（本轮创新开始前）的完整备份。

## 怎么打开

**方式一（推荐，若根目录的版本索引服务器开着）**

浏览器打开：<http://127.0.0.1:8891/backup_0/>

**方式二（单独运行）**

双击本文件夹里的 `打开网站.cmd`，或在本文件夹里执行：

```
node serve.mjs 8901
```

然后浏览器打开：<http://127.0.0.1:8901/>

> 不能直接双击 `index.html`：页面用 ES 模块 + fetch 读数据，`file://` 会被浏览器 CORS 拦掉。
