2. **一句话概念**（评委第一眼会不会说“哦，这个新”）：
   **「渐隐」——一个 30 秒的能力流失体验馆**：你选一种能力（视力 / 听力 / 注意力），看着它在你眼前被一年一年地拿走。不是告诉你“看不清有多难”，而是让你亲自经历一次。

3. **现实意义**（说得出口的痛点）：
   科普只给数字——“全球约 22 亿人视力受损”——正常人看完转发一下就忘了。**共情赤字**才是无障碍倡导真正的阻力。
   痛点的原话版本：**“你跟我说「我看不清」，我以为只是有点模糊；等我自己经历一次，我才知道那是连对面的人脸都认不出来。”**
   具体落点：助残日 / 无障碍宣传周 / 社团招新的展台，扫码就能体验，一个人 30 秒，不需要志愿者在旁边讲。

4. **核心功能闭环**（输入 → 处理 → 输出，30 秒能演示）：
   - **输入**：选一种能力（视力 / 听力 / 注意力）+ 一段内置素材（一张人像照 / 一段双人对话 / 一段阅读文本）
   - **处理**：时间轴 0 → 第 N 年，**参数化退化引擎**按年份推进：视野收缩、对比度衰减、色觉偏移、高频丢失、背景噪声、干扰层叠加；可暂停、可拖回任意年份、可与第 0 年左右对比
   - **输出**：一张“这是我在第 X 年看到的世界”卡片 + 一份可分享的体验报告 + 首页实时聚合统计
   - **30 秒演示动作**：点“开始”→ 全场安静 30 秒 → 一张清晰的脸逐渐认不出来 → 拖滑块回到第 0 年，对比一眼

5. **数据留存**（打卡 / 记录 / 排行 / 上传 / 收藏——后端 10 分靠它）：
   - **体验记录**：每次体验落库（场景、时长、是否完成、停在第几年、中途拖回过几次）→ CloudBase 云数据库
   - **认知前后测**：体验前 / 后各 1 题（“你觉得自己能理解这种困境吗” 1–5 分），存**态度改变差值**——这是整个项目最有说服力的一份数据
   - **聚合看板**：首页展示“已有 N 人次体验 · 平均认知改变 +X%”（云函数定时聚合）
   - **报告卡**：每份报告带唯一 id 与**参数 JSON**，别人打开能精确复现同一画面（可收藏、可传播）
   - **我的历史**：匿名 session id 记录打卡与历史，不建账号
   - 后端 3 个云函数：`record`（写记录）/ `report`（生成与读取报告卡）/ `stats`（聚合）

6. **刺**（别人 7 天学不会、套不了壳的真功夫；没有就写“无刺”）：
   三项真功夫，都不是“套个滤镜”能达到的：
   - **参数化退化模型**：把“视力衰退”拆成 5 个**独立且可解释**的参数（视野 / 对比度 / 色觉 / 模糊 / 闪光敏感），每个年份对应一张参数表，而不是一键 `blur()`。答辩时能指着参数说“第 3 年丢失的是这一项”。
   - **三种侵蚀实现的对比与选型**：Canvas 像素级侵蚀 vs CSS mask 碎片化 vs WebGL 噪声着色器，给出一张**移动端帧率 × 视觉可信度**的实测对比表，并讲清为什么选 X、怎么降级。
   - **可复现的参数卡**：报告存参数 JSON，任何设备打开都能逐帧复现同一画面——这是“体验能被传播、能被引用”的技术基础，也是别人抄界面抄不走的东西。

7. **7 天计划**（M0 双上线 / M1 页面全 / M2 核心通+刺评审 / M3 冻结，各一句）：
   - **M0 双上线（D1–D2）**：前端骨架 + 3 个云函数（record / report / stats）打通并出第一个公网链接；同时跑通最硬的 Demo——一张图在浏览器里按年份实时退化。
   - **M1 页面全（D3–D4）**：首页 / 场景选择 / 体验页 / 报告页 / 统计页 / 关于页全部能点通（哪怕是空壳），素材与文案补齐。
   - **M2 核心通 + 刺评审（D5–D6）**：三个场景全部可体验，退化参数定稿，移动端帧率达标；组内做一次“刺评审”——三项刺必须讲得清、数据必须能复跑。
   - **M3 冻结（D7）**：只修 bug，录 90 秒演示视频、写说明页、彩排三分钟。

8. **主动砍掉的**（写清不做什么）：
   - **不做第 4、5 种病种**（读写困难、慢性疼痛不做）——只做视力 / 听力 / 注意力三个，做深不做全
   - **不做医疗诊断、不给医学建议**——参数全部标注“科普近似，非临床”
   - **不做账号、评论、排行榜**——只有匿名记录，不做社交
   - **不上传用户的照片和录音到服务器**——素材本地处理，隐私红线
   - **不做 3D、不做视频、不做多语言**
   - **不做捐赠 / 募捐跳转**——不把公益做成卖惨

9. **风险与降级阀**（最坏情况怎么兜底）：
   - **WebGL 在低端机跑不动** → 降级到 Canvas 2D + 预渲染关键帧，保底 30fps；再不行降成 CSS 滤镜版
   - **退化参数找不到权威来源** → 只上“视力”一个场景，参数标“近似”并附来源，不做无依据的精确数字
   - **后端挂了 / 现场没网** → 体验与报告全本地可跑，后端只影响统计；**断网也能完成 30 秒演示**
   - **素材版权** → 全部 CC0 / 自摄 / 自录，记进 `docs/design/素材来源.md`
   - **被评“卖惨”** → 不配煽情音乐、不用悲情文案，结尾给三件可执行的小事（调一次屏幕亮度 / 打开一次无障碍设置 / 了解一个志愿渠道），用前后测数据说话
