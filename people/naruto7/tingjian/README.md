# 听见校园（重做版）

组长 naruto7 的重做。以刻声为资产，从头搭：屏风 → 留声机，四个板块（留声机 · 社区 · 年轮 · 我的），全站颜色跟着钟点走。设计规则在 [DESIGN.md](DESIGN.md)，先读它。整理：ClawsGO Science Agent，2026-11-24。

## 跑起来

最省事：双击 `启动.cmd`（或仓库外面的 `E:\走软小组\听见校园-双击启动.cmd`），浏览器会自己打开 http://127.0.0.1:8790/?screen=1 。黑窗口别关，关了网页就停。

```bash
cd people/naruto7/tingjian
npm install
npm run dev              # http://127.0.0.1:5273 ，自带 /api（本机文件存储，数据在 .data/）
npm run build
npm run serve            # 构建好的页面 + /api，http://127.0.0.1:8790 ；加 --host 0.0.0.0 给局域网里的手机扫
```

演示时固定钟点：网址加 `?h=18.5`；强制出现屏风：加 `?screen=1`；画质：`?q=lite` 低、`?q=mid` 中、`?q=full` 高（网址指定时不再自动降档）。

画质分三档（`src/stage/scene.js` 的 `TIERS`）：高 = 像素比 1.5、4× 抗锯齿、环境光遮蔽、4096 阴影；中 = 像素比 1.25、不开这两样、2048 阴影；低 = 像素比 0.75、1024 阴影。起点：独显高、核显中、软渲染和触屏低；稳定后量 45 帧，中位数超过 40 毫秒就降一档，落定的档记在这台设备上。场景分几步搭、着色器在屏风后面先异步编好，屏风盖着时画布不画。

## 上云（CloudBase）

1. 在 `.env` 填 `TCB_ENV_ID`、`TCB_SECRET_ID`、`TCB_SECRET_KEY`（照 `.env.example`；`.env` 不进仓库）。
2. 数据库：2026-10-30 以后新建的环境是 PostgreSQL，文档型接口要靠「文档插件」。部署脚本的 `db` 步骤会开插件、建 14 个集合（discs、echoes、photos、heard、favs、reports、posts、replies、reacts、topics、relays、albums、tracks、files）。声音和照片也存进数据库的 `files` 集合，不走云存储：新环境的云存储要另建存储桶、另配服务端密钥。子用户要有云开发、云函数、对象存储三项权限（对象存储给静态托管用）。
3. `npm run build && npm run deploy:cloudbase`：页面进静态托管，接口进云函数 `api`，挂在同域 `/api`。
4. 云函数的环境变量设 `KS_ADMIN_TOKEN`（审核口令），照片才有人放行。

**状态（2026-11-24 晚）：** 已上线。页面 https://sure-fish-d0gpj5x9pb635dbb5-1539820249.tcloudbaseapp.com/ ，接口 https://sure-fish-d0gpj5x9pb635dbb5.service.tcloudbase.com/api 。从外网走过一遍：发帖、刻一张（取回的声音逐字节一致）、钉一句、「我的」、真删（删后取声音 404）；无头 Chrome 打开线上社区页，15 条示例帖都在，控制台与网络问题 0 条。

## 已知缺口

- 限频记在云函数实例的内存里：多实例时各算各的。课程规模够用。
- 页面每 30 秒取一次 `/discs`、`/feed`、`/me`，每次在服务端是十来次数据库读。答辩现场人多时要算资源点，可以把间隔调长。
- 真实录音 0 段。231 张示意盘和 41 段史料撑着画面；人数只数真实的。
- 照片审核没有界面，只有接口（`/api/admin/...`）。
- 手机上的三维走的是同一套场景，省电档；没有在真机上量过帧率。
- 加载（2026-11-25，AMD 610M 核显、1440×900）：改之前进站第一帧要现编约 50 个着色器，主线程连卡 3.3 秒和 1.5 秒，之后高画质只有 8–20 帧；改之后屏风期间最长一次卡 0.7 秒（阴影深度的着色器没有异步接口，在屏风上读字时发生），进站后 0 卡、55–60 帧。独显上没量过。
