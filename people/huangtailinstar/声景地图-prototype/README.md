# 声景地图 · 今晚 Prototype（个人原型备份）

> 本目录是 huangtailinstar 的个人原型备份，放在 `people/` 下，**不进构建、不参与评审**。
> 个人原型阶段的技术栈为 React + TypeScript + Vite + Tailwind（团队共享技术栈 Vue3 的选型以 `AGENTS.md` / 组长拍板为准，此处仅记录本人原型实现，未并入 `src/features/`）。
> 口径依据：`docs/design/评分口径与MVP验收.md`（v0.1，2026-11-23）。

## 一句话立意

**把校园里会消失的声音钉在地图上，留给以后的人听。**
（草案，组长定稿后首页、PPT、README 引用同一句。）

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建，产物在 dist/
```

Node 20+。地图素材 `public/campus-map.png` 为裁剪后的北航学院路校区平面图（仅地图主体，无图例注释）。

## 数据口径（对齐评分文档 §5.3 / A6）

- 本原型内所有声片均为 **placeholder（示例）**：由 Web Audio API 现场合成（鸟鸣、风声、雨声、脚步、翻书等 12 种声景），无外部音频文件，无真人录音。
- 示例数据在 `src/data/seed.ts` 中生成，**全部为自制/合成，不含真人真地录音**，文案不作为真实采集记录展示。
- 统计口径：当前为原型演示，**尚未接入 real 数据**。若进入正式 MVP，需按 §5.3 给每条数据补 `demo: true` 标记与 `来源` 字段，并在"关于"页写清 n 条真实 / m 条示例，统计只数 real。
- 采集合规：本原型未采集任何人声对话；地点仅到建筑/区域级；地图为裁剪的校区平面图。

## MVP 对照（评分文档 §5.2 六板块，本原型已覆盖的结构）

| 板块 | 本原型对应 | 状态 |
|---|---|---|
| 首页 | 主页：一句话立意 + 会响的唱片开场 + 创建入口 | 示例（可点出声） |
| 地图 | 社区/我的地图：声音点 + 时段/类型筛选 + 声片卡 | 示例 |
| 刻 | 两段式创建：选地点→录音→拍照→写一句，接着可选增强（记忆类型/合辑/可见范围/时间胶囊） | 示例（录音存本机） |
| 回应 | 唱片详情内的"回声"小区域 + 共鸣"被打动" | 示例 |
| 时间 | 数据地图：情绪热力、声音活跃度、安静角落、时段声景变化 | 示例 |
| 关于 | 数据来源/口径见本 README；正式 MVP 需独立"关于"页（待并入项目线） | 即将开放 |

## 三态规则（§5.4）自查

- 所有可见入口均可点、有结果；无空白页、无报错（浏览器实测控制台 0 错误）。
- 尚未实现的功能（真实后端、线上部署、注册登录、图片上传）**未伪装成可用**，本原型仅作个人备份，不进演示。
