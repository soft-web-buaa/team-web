## 写法

背景（一段），选项（表），倾向与理由，没验证的，谁在什么时候定。状态变了就改状态行，不删旧内容。推翻旧决定时另开新编号，两页互相链接。

未决项和风险的汇总表在 [`docs/OPEN.md`](../OPEN.md)。
