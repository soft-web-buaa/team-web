# 决策记录 0006：数据放哪，照片怎么用

> 状态：已按组长 2026-11-24 的两条意见实现 MVP，后端真接入与审核人待定。整理：ClawsGO Science Agent，2026-11-24。
> 接 [0001](0001-后端选型.md)、[0005](0005-首页改成留声机与回声层.md)。

## 背景

组长 2026-11-24 的两条意见：

1. 照片不要框死用途和权限。唱片套子只是一个举例和一个小细节，社区分享、地点页里都可以用。设计与巧思是整个项目的 motto。
2. 照片"只存本机"是错的：整个项目都是上云的，要想清楚哪些放本地、哪些放云。

上一版（PR #23）把"后端还没接"写成了"回声只存本机"，两件事混在了一起。这一版把数据的归属先定下来，页面按云优先写，云不通时才退到本机。

## 数据放哪

| 放哪 | 内容 | 理由 |
|---|---|---|
| 云 | 声片与档案、回声、照片（缩略和大图）、落款快照、同听、举报与审核状态、同意记录、计数 | 别人要看到的、要长期在的、要统计的，都以云为准。计数由服务端算，页面只显示 |
| 本机 | 发件箱（还没发出的话和照片）、"对我隐藏"、录到一半的声音、画质档 | 只有我自己要用，或者丢了能重新来。断网时先落发件箱，页面写"待发出"，网络回来自动发 |
| 不留 | 照片里的 EXIF（含拍摄地点的经纬度） | 设备上重新编码时去掉，服务端对每一张再剥一遍。前端的检查可以被绕过 |

私密盘默认只有自己看得到，也存云上，这样换设备还在，也能一键真删。

## 照片怎么用

没有"只能放套子"的限制之后，做了这几处，其余写进 [未竟之业](../design/全盛形态与未竟之业.md)：

| 用法 | 做法 |
|---|---|
| 钉在某一秒 | 回声可以配一张照片。针走到那一秒，照片像相纸一样显影。回声带的钉、列表、盘面上都能看出这一条带照片 |
| 地点的印样 | 地点页一条"这里的照片"，一格一张，最新的在前，点开是大图 |
| 套子换面 | 地点有审核通过的社区照片时，套子正面换成最新的一张，角标写"来自社区"；没有就用模型照，角标写"模型照" |

规矩：照片是辅，声音是主线；每张照片的来源如实标；没有照片的地方不放假图。

## 审核与安全

| 事项 | 做法 |
|---|---|
| 照片 | 先审后显。通过之前只有上传的人自己看得到，并写着"审核中"。每张上传前要勾选"照片里没有能认出身份的人，或我已经问过"，同意版本一并存档 |
| 文字 | 先显后审。服务端重做链接和号码拦截并限频；三个不同的人举报就先收起，等人看 |
| 图片文件 | 服务端只收 JPEG，限尺寸和体积，剥掉 APP1 到 APP15 和注释段（EXIF、XMP、定位） |
| 作者键 | 请求头 `x-ks-key`，是刻声卡摘要，不是登录。接 CloudBase 匿名登录后由云端 uid 代替 |

## 现在是什么、不是什么

- `scripts/dev-cloud.mjs` 是**开发用云模拟器**，实现 `contract.js` 里的接口，数据在内存里。`npm run dev` 与 `npm run preview` 自带 `/api`。它用来验证"A 留的话，B 看得到"，不是后端选型的替代。
- 构建出来的静态文件里没有它：部署到哪里，`/api` 就要指到哪里的云。指不到时页面不报错，话留在发件箱里，显示"待发出"。
- `check:cloud` 44 项和 `e2e:kesheng` 里的"另一个浏览器环境的 B 看得到 A 钉的话"都是对模拟器的验证，不是对 CloudBase 的验证。CloudBase 我没有注册过，也没有调用过。

## 选项

| 选项 | 好处 | 代价 |
|---|---|---|
| A 本机优先，后端再说（PR #23 的做法） | 简单 | 与"整个项目上云"冲突；别人看不到，不算社区 |
| B 云优先，本机是发件箱和缓存（本次） | 数据只有一份真相；断网不丢话 | 要定契约、要写服务端校验、要有人审照片 |
| C 照片放第三方图床 | 省存储 | 国内访问、合规、删除权都不在自己手里 |

## 没验证的

- CloudBase 全部来自文档检索。契约里的接口要映射成云函数加云存储，这一步没做。
- 页面每 15 秒去云上取一次这张声片的回声：这在 CloudBase 免费额度（每月 3000 资源点，见 0001 的 R1）下是否撑得住，没算过。答辩现场多人同时开页面时尤其要算。倾向：改成"页面可见时才取，且在发出话之后立刻取一次"，上线前定。
- 手机拍照上传的真机流程没测。iPhone 默认的 HEIC 格式在非 Safari 浏览器里 `createImageBitmap` 可能读不出，页面会提示换成 JPEG，这条路没验证。
- 谁来审照片、多久审一次：没有人定。答辩前必须有人在，否则"先审后显"会让所有照片一直在审核中。
- 人脸与隐私：勾选只是留痕，不能替代审核。
