## 常用命令

```bash
cd people/naruto7/mvp
npm install
npm run dev                # 开发
npm run e2e                # 构建 + 58 项走查，需要本机 Chrome 或 Edge；找不到时设 CHROME_PATH
npm run e2e:kesheng        # 留声机冒烟 20 项（要先构建过，或不加 --no-build）
npm run check:sounds
npm run check:contrast
npm run check:echoes

# 示例回声和套子照片是脚本生成的：声音配方或地点变了就重跑
node scripts/make-echo-seed.mjs
node scripts/make-sleeve-photos.mjs          # 先起 npm run dev -- --port 5199
python scripts/subset-plan-font.py <ZhuqueFangsong-Regular.ttf>   # 页面加了新字时补字体

# 推送之后回头核对是否进了 main（PR 可能在你推完之前就被合并，这一轮又发生了一次）
git fetch && git merge-base --is-ancestor <提交> origin/main && echo 已进 main
```
