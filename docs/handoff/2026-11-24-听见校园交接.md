- **首页是留声机**：整屏嵌入组长个人作品「刻声」的三维分区图（副本在 `public/kesheng/`，已进 main）。原首页挪到 `/now`。

- **待组长合并（PR #27）**：数据按云优先重新安排（决策 0006）。回声可以配照片，设备上去掉定位信息，勾选同意，先审后显；针走到那一秒照片显影；地点页有印样；有社区照片时套子换面。服务端重做文字校验、限频、JPEG 去 EXIF，举报满三人先收起。
- **没有真后端**。开发用云模拟器（`scripts/dev-cloud.mjs`）随 `npm run dev` 和 `preview` 自带 `/api`，能验证"A 留的话，B 看得到"，不能验证 CloudBase。"后端还没接"和"只存本机"是两回事，别再混着说。
- **下一步**：选基线（见 0004）、定后端（见 0001）、定照片谁来审（见 0006）、采集真实录音、决定两份声音数据怎么合并（见 0005）。
