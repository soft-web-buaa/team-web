# GitHub 三分钟地图（咱们项目版）
> 这一页看完就能上手。往后每天照着"每天三步"走，具体规范 AI 会按仓库里的规则自动执行。

## 先看一句话
GitHub = 咱们代码的"云盘 + 作业本"。你电脑上有一份副本，每天开工把最新版拿下来，收工把自己做的那部分传上去。

## 名词对照（重点看"跟你的关系"这一列）
| 词 | 在咱们项目里是什么 | 跟你的关系 |
|---|---|---|
| 组织 soft-web-buaa | 咱们组在 GitHub 上的地盘，像班级群 | 加进来就行 |
| 仓库 team-web | 咱们全部代码所在的唯一文件夹 | 知道它在哪就行 |
| 你的目录 `src/features/<名字拼音>/` | 你只在这个小文件夹里干活 | **记住：只动自己的目录** |
| 分支 | main = 主稿（永远能跑）；feature/xxx = 你的草稿 | 交 AI / Desktop 处理 |
| 提交 commit | 存档点：保存 + 一句备注 | AI 处理 |
| PR | "我的草稿写完了，申请合进主稿" | 收工群里报一句 |
| Issue 任务卡 | 看板上的一张任务卡：做什么、怎么算做完 | 开工扫一眼 |
| 看板 | 任务白板，四列：待办 / 进行中 / 完成 / 砍掉 | 开工扫一眼 |
| 里程碑 M0–M4 | 一周的阶段：周一上线 → 周日收尾 | 知道现在到第几个就行 |
| 团队 web | 组织里的权限分组 | 权限组里统一配好 |
| 包（依赖） | 项目用的现成组件 | 装什么组里统一决定 |

## 每天三步
1. **开工**：打开你的工具，贴一句开场（模板在 `docs/ai-开场模板.md`，只填 3 个空）；
2. **干活**：和 AI 结对，卡 30 分钟就群里喊人；
3. **收工**：群里发一句"<名字>：<X> 做完了，PR #N"。

> 工具差别只差一次点击：Trae / WorkBuddy / DSH 会自动提交，你只需管每天两句；用 ChatGPT 网页版的话，收工按 03 手册在 GitHub Desktop 点两下再发那句。

## PR 怎么合（2026-11-22 起）
- 一律走 PR（main 有保护，直接推会被拦，这是正常的）。
- **不要求别人 approve，也没有必过检查**——PR 发出来，自己点 **Merge pull request** 就行。
- 唯一硬规矩：只动自己的位置（`people/<你的名>/` 或自己认领的切片）；碰公共文件（路由、配置、样式变量）先在群里说一声。

## 三个最常翻车的点（干的时候顺手防掉）
1. **子页面刷新白屏**：做完一个页面，点进去按一下 F5，不白屏才算完（地址栏里带 # 就对了）；
2. **别人乱输搞坏页面**：做完输入框，往里面输一句 `<b>测试</b>`——原样显示成字符 = 安全，显示成加粗 = 要改；
3. **手机打不开/挤成一团**：做完用自己的手机点一遍；答辩前安卓和 iPhone 各试一次。

## 一条红线
只动自己的目录；公共文件（路由、配置、样式）要动，先在群里说一声。其余任何问题，群里喊——没有哪件事需要你一个人扛。
