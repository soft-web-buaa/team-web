# 创意提案 · 集合入口

周日定题会之前，六个人的提案都汇总在这里。**同权过闸，不排名、不打分。**

## 两个地方，别混
| 地方 | 是什么 | 放什么 |
|---|---|---|
| `docs/ideas/`（这里） | 集合：规则 + 索引 | 提交说明、提案索引、评审结论 |
| `people/<GitHub 名>/` | 个人文件库 | 原始素材、参考名单、草稿、截图 |

## 怎么投（网页上 30 秒）
1. 进 `people/`，点 **Add file → Create new file**。
2. 文件名写 `people/<你的 GitHub 名>/提案卡.md`（斜杠会自动建目录）。
3. 复制 [`people/_模板/提案卡.md`](../../people/_模板/提案卡.md) 的内容，填九行，页面底部 **Commit changes**。

不想写卡也能参加：周日会上 2 分钟口述，照那九行说。

## 规则
- 不排名、不打分、不评审；五关只在周日现场走。
- 不放密钥、真实个人信息、对同学作品的评价；素材标来源，核不了的标 `[U]`。
- 大文件（视频 / 原图 > 10 MB）不传，放群网盘并在卡里写链接。

## 五关
可行性 → 标新立异 → 刺（别人 7 天学不会的点）→ 现实意义 → 数据留存。
