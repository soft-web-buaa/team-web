# 素材去哪找（一句话清单）
> 做页面要找图、图标、字体，认准下面这几个，别的来源先别用——合规分就落在这条上。

| 要什么 | 去哪拿 | 注意 |
|---|---|---|
| 图标 | iconfont.cn，挑"可商用"集合 | 下载时记下作者/集合名 |
| 字体 | 思源黑体/宋体（开源可商用） | 正文用系统字体栈兜底（YaHei/PingFang） |
| 图片 | Pixabay.com（可商用，不用登录） | 别用百度随便搜的图 |
| Logo/配色/视频 | 组里统一出，有专人负责 | 别自己另做一套 |

习惯一条：**每用一张图，顺手在 `docs/design/素材来源.md` 记一行**（图片名 → 来源链接）。答辩要查素材来源，这张表就是答案；攒到最后一晚再补会补到哭。
