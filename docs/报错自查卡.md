# 报错自查卡（卡住先看这里，10 条）
> 用法：遇到报错按"长得像"对号入座，照"下一步"做一遍；还不行就群里喊人，附上**报错原文截图 + 你试过的最后一步**。

1. 装包卡很久报 `npm ERR! ... ETIMEDOUT / ECONNRESET`
   为什么：默认下载源在国外，校园网连不稳。
   下一步：项目根目录已经放了 `.npmrc` 国内镜像（clone 下来就有）；还慢就执行 `npm config set registry https://registry.npmmirror.com` 再装一次。

2. 数据请求失败，控制台红字带 `CORS / Access-Control-Allow-Origin`
   为什么：浏览器不让页面跨域名取数据，需要后端放行。
   下一步：这是后端的事，群里喊一句"接口 CORS 没放行"，组里统一加。

3. 首页能开，点进内页一刷新就 404/白屏
   为什么：地址栏的路由是浏览器"演"出来的，服务器上没有那个文件。
   下一步：路由要设成 hash 模式（地址里带 #）。遇到就群里报一句，组里统一改。

4. `git push` 被拒，提示 `rejected / fetch first`
   为什么：别人先推了，你的草稿落后一步。
   下一步：先 pull 再 push；**不要** force push，搞不定群里喊。

5. 改了代码，刷新页面没变化
   为什么：多半是缓存，不是代码没生效。
   下一步：先硬刷新（Ctrl+Shift+R）或无痕窗口再试；还不行再怀疑代码。

6. `git status` 里一大片文件，混着 node_modules
   为什么：node_modules 是装出来的依赖，不该进仓库。
   下一步：`git rm -r --cached node_modules` 把它请出去；其他拿不准的文件先别提交，群里问。

7. 合并时 `package-lock.json` 冲突 / 装依赖报版本错
   为什么：依赖清单被两个人同时动过。
   下一步：自己不处理，群里喊，组里统一决定留哪版。

8. 本地跑不起来，提示环境变量没有 / 接口地址 undefined
   为什么：密钥和接口地址放在 `.env` 里，每人要自己复制一份。
   下一步：照着 `.env.example` 复制改名为 `.env`，填上自己的值（值问组里要）。

9. 电脑上正常，手机打开挤成一团、字小如蚁
   为什么：页面没告诉手机"按你的屏幕宽度显示"。
   下一步：确认 `index.html` 里有 viewport 那行（Vite 模板默认有，别删）；没有就群里报。

10. 调接口直接失败或超时（5xx）
    为什么：后端代码报错、没部署，或环境没配。
    下一步：先确认后端已经部署过；不行群里喊，附上状态码，后端归组里统一修。

> 原则：卡 30 分钟就喊人——这是查卡的时间上限，不是硬扛的期限。
