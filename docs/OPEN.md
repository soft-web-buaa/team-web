## 三、文档与实际不一致

- `AGENTS.md` §1 写"npm 走仓库 .npmrc 国内镜像"，仓库根目录没有 `.npmrc`（2026-11-24 查）。
- 国内镜像 `registry.npmmirror.com` 不支持 `npm audit`，会返回 404。审计时加 `--registry=https://registry.npmjs.org/`。
- `AGENTS.md` §5 要求素材每张记进 `docs/design/素材来源.md`，这个文件还没有创建。目前已知的素材：字体（霞鹜文楷 OFL 1.1 与 MIT，Barlow Condensed OFL 1.1，随包部署）、校史史料音频（授权状态见"关于"页）、刻声副本里的第三方代码（three.js 与 fflate，MIT）和地图数据（OpenStreetMap，ODbL）。
